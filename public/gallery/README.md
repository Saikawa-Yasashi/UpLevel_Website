# Gallery Images

Drop project photos in this folder. Supported formats:

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.avif`

Use descriptive filenames for easy organization, for example:

- `kitchen-walnut-cabinets-01.jpg`
- `jackson-custom-home-exterior-01.jpg`
- `staircase-white-oak-01.jpg`

After adding images, commit and redeploy the site. Images appear automatically — no code changes needed.

Hidden files and README files are ignored.
